# Contributing

Thanks for considering a contribution to this project.

## Ways to contribute

- Open an issue to report bugs, request features, or ask questions.
- Submit a pull request with a clear description of the change.
- Improve prompts, research quality, or frontend flows when you identify a defect or opportunity.

## Development workflow

1. Create a feature branch from the default branch.
2. Keep changes focused and easy to review.
3. Run the relevant checks before opening a pull request.
4. Share the exact behavior you changed and any setup notes needed to reproduce it.

## Pull request expectations

- Explain the problem and the solution.
- Include any required environment variable updates.
- Keep the scope narrow and ensure the change is understandable to the maintainers.

## Coding conventions

- Prefer readable, well-documented Python.
- Use existing project patterns in the `src/` and `frontend/` directories.
- Avoid broad refactors unless they are required for the task.

Please keep discussions constructive and focused on improving the project.
